## Estructura del Proyecto:
- **`jonathan.html`**: Archivo HTML principal con diseño editorial minimalista, paleta Esmeralda & Menta Tech, catálogo interactivo de requerimientos, stack tecnológico y lienzo interactivo de Figma.
- **`css/styles.css`**: Hoja de estilos modular desacoplada con sistema de diseño centralizado en `:root` (Custom Properties), Flexbox y CSS Grid.
- **`img/`**: Logotipo y recursos visuales oficiales de CALJIM.

## Stack Tecnológico Propuesto:
- **Frontend**: HTML5 Semántico + CSS3 + JavaScript ES6+ (Fetch API) + Leaflet.js (Mapas/GPS) + Chart.js (Dashboard analítico).
- **Backend**: PHP 8.x con PDO bajo arquitectura MVC y seguridad RBAC.
- **Base de Datos**: MySQL administrado con phpMyAdmin en XAMPP.
- **Reportes & Facturación**: DomPDF para comprobantes fiscales y guías de despacho digitales en PDF.
