## Estructura del Proyecto:
- **`jonathan.html`**: Maquetación individual
- **`index.html`**: Versión base del equipo.
- **`img/`**: Logotipo y recursos visuales.

## Stack Tecnológico Propuesto:
- **Frontend**: HTML5 Semántico + CSS3 + JavaScript ES6+ (Fetch API) + Leaflet.js (Mapas/GPS) + Chart.js (Dashboard analítico).
- **Backend**: PHP 8.x con PDO bajo arquitectura MVC y seguridad RBAC.
- **Base de Datos**: MySQL administrado con phpMyAdmin en XAMPP.
- **Reportes & Facturación**: DomPDF para comprobantes fiscales y guías de despacho digitales en PDF.
