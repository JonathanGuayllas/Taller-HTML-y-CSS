Sección 02

Requerimientos Funcionales

Lista organizada y filtrable de requerimientos con tipografía optimizada para lectura descansada.

RF-01 Materiales e Inventario

Gestión y Consulta de Inventario en Tiempo Real

El sistema debe permitir a los administradores registrar, actualizar y dar de baja el stock de materiales áridos. Los clientes podrán visualizar en la web la disponibilidad actualizada de cada producto en vivo.

RF-02 Materiales e Inventario

Cálculo y Selección de Volumen en Metros Cúbicos (m³)

La interfaz de pedido debe permitir al usuario calcular o indicar el volumen necesario en m³, calculando automáticamente el precio unitario, subtotal y total estimado con impuestos.

RF-03 Logística y Despacho

Flujo Optimizado de Pedidos Tripartito

El sistema debe sincronizar el ciclo de vida del pedido entre cliente, operario/conductor asignado y la administración central, notificando cambios de estado (solicitado, confirmado, cargado, en tránsito, entregado).

RF-04 Logística y Despacho

Monitoreo y Rastreo del Viaje en Tiempo Real

El cliente dispondrá de un mapa interactivo satelital para visualizar el trayecto en tiempo real del vehículo que transporta su pedido hasta el lugar de entrega programado.

RF-05 Logística y Despacho

Trazabilidad y Rutas de Maquinaria Pesada

El sistema registrará la ruta georreferenciada de los operarios al conducir maquinaria pesada, generando históricos de velocidad, trayecto, tiempos de parada y auditoría operativa.

RF-06 Maquinaria y Mantenimiento

Control de Estados de Equipos y Maquinaria

El sistema debe clasificar y mostrar en tiempo real el estado de cada unidad de maquinaria pesada: Disponibles, Alquilado, En Ruta y En Mantenimiento.

RF-07 Maquinaria y Mantenimiento

Gestión de Mantenimiento Preventivo y Correctivo

Permite programar alertas automáticas de mantenimiento por horas de uso/kilometraje y registrar intervenciones correctivas, repuestos utilizados, historial y costos asociados.

RF-08 Talento Humano y Nómina

Registro Digital de Horas Laborales

Registro sistemático de las jornadas y horas efectivas trabajadas por cada operario mediante marcación digital o asignación a órdenes de trabajo en campo.

RF-09 Talento Humano y Nómina

Liquidación Automatizada de Pagos y Nómina

El sistema calculará el valor neto a pagar a cada trabajador en función de las horas laboradas, horas extra y tarifas preconfiguradas, emitiendo comprobantes de liquidación.

RF-10 Comunicación Operativa

Canal de Comunicación / Mensajería Interna

Módulo de mensajería interna y notificaciones push entre la administración y los operadores en campo para asignación de tareas, cambios de ruta e incidencias mecánicas.

RF-11 Facturación y Finanzas

Emisión de Facturación Electrónica

Generación y descarga de facturas y comprobantes detallados con desglose de IVA, metros cúbicos de árido, costo de flete/transporte y servicios de alquiler adicionales.

RF-12 Facturación y Finanzas

Métricas y Reportes Analíticos de Ventas

Dashboard interactivo con analítica de negocios: gráficas de volumen despachado, ventas brutas y netas, filtrables dinámicamente por día, mes o año.

Sección 03

Criterios de Calidad

Estándares de resiliencia, seguridad, rendimiento y disponibilidad del sistema.

RNF-01 Disponibilidad

Alta Disponibilidad Cloud (24/7)

La plataforma operará sobre infraestructura cloud garantizando un uptime continuo del 99.5%, accesible permanentemente desde navegadores modernos.

Objetivo SLA ≥ 99.5% Uptime
RNF-02 Usabilidad

Diseño Adaptativo & Mobile-First

Interfaz optimizada para terminales de oficina y pantallas táctiles de smartphones o tablets utilizadas por los operarios en las zonas de obra.

Enfoque UI 100% Adaptativo
RNF-03 Rendimiento

Velocidad & Geolocalización en Vivo

Consultas de catálogo e inventario en menos de 2 segundos, y sincronización satelital periódica de las unidades en trayecto.

Latencia < 2s | 5-10s GPS
RNF-04 Seguridad

Control de Acceso RBAC & Cifrado

Mecanismo de autenticación mediante tokens seguros (JWT) con separación estricta de permisos según los roles de Administrador, Operario y Cliente.

Seguridad RBAC + JWT
RNF-05 Integridad

Transaccionalidad & Respaldo Diario

Operaciones atómicas (ACID) en base de datos para prevenir inconsistencias financieras, respaldadas por copias de seguridad diarias automatizadas.

Respaldo ACID + Backup 24h
Sección 04

Stack Tecnológico Propuesto

Arquitectura modular y tecnologías seleccionadas para la construcción integral de la plataforma CALJIM.

Capa Frontend / Cliente

HTML5 Semántico + JS Moderno

Interfaz web adaptativa enriquecida con interactividad nativa y librerías especializadas para mapas satelitales y analítica de datos.

  • HTML5 Semántico + CSS3: Maquetación adaptativa accesible y variables globales.
  • JavaScript ES6+ (Fetch API): Peticiones asíncronas para inventario y estados en tiempo real sin recargar página.
  • Leaflet.js + OpenStreetMap: Visualización interactiva satelital y rastreo GPS de maquinaria en tiempo real.
  • Chart.js: Dashboard analítico con gráficas dinámicas de ventas y volumen despachado en m³.
Capa Backend / Servidor

PHP 8 con Arquitectura MVC

Lógica del servidor estructurada en capas desacopladas, comunicación segura con la base de datos y control de accesos RBAC.

  • PHP 8.x: Motor robusto de procesamiento del lado del servidor.
  • PDO (PHP Data Objects): Consultas preparadas para máxima protección contra inyecciones SQL.
  • Patrón MVC: Separación ordenada de responsabilidades en Controladores, Modelos y Vistas.
  • Control de Acceso RBAC: Gestión estricta de permisos según los roles Administrador, Operario y Cliente.
Capa de Datos / Persistencia

MySQL / MariaDB (Motor InnoDB)

Almacenamiento relacional diseñado para garantizar atomicidad y consistencia en los despachos, inventarios y finanzas.

  • Motor InnoDB: Soporte nativo para transacciones seguras bajo estándar ACID.
  • Entorno XAMPP: Servidor Apache y gestor de datos integrado para desarrollo ágil.
  • phpMyAdmin: Consola web para modelado de tablas, relaciones y consultas de prueba.
  • Políticas de Respaldo: Esquema de copias de seguridad diarias automatizadas.
Servicio de Facturación

DomPDF (Generación de Comprobantes)

Módulo automatizado para la creación de comprobantes fiscales electrónicos y guías de transporte descargables.

  • Librería DomPDF: Renderizado directo de plantillas HTML y CSS a documentos PDF de alta fidelidad.
  • Facturación Desglosada: Detalle automático de IVA, volumen en m³, fletes y servicios de maquinaria.
  • Descarga Inmediata: Disponibilidad de comprobantes digitales tanto para el cliente como para el conductor.
  • Historial de Nómina: Liquidación impresa para operadores de campo según horas efectivas trabajadas.
